# 최소곡면 갤러리 (three.js, 우윳빛 유리)

평균 곡률이 어디서나 0인 **최소곡면**들을 우윳빛 유리 곡면과 메시 곡선으로, 성운 배경 위에 그립니다.
`index.html` + `surfaces.js` 로 동작합니다(three.js r170 CDN).

## 곡면족

| 곡면족 | 매개변수 | 자료 / 방법 |
|---|---|---|
| 코스타–호프만–미스 | 종수 k = 1~6 | `w^(k+1) = z^k(z²−1)`, `g = c/w`, `dh = dz/(z²−1)`. 2(k+1) 조각을 맞붙임. 매장, 현수면 끝 2 + 평면 끝 1 |
| 현수면–나선면 | 연합족 각 θ (0°~90°), ▶ 변형 | `f = 1/z²`, `g = z`. θ = 0 현수면, 90° 나선면 한 바퀴. 길이·각도가 그대로인 등거리 변형 |
| 에네퍼 | 차수 n = 1~5 | `f = 1`, `g = zⁿ` |
| k-노이드 (조르지–미스) | 끝 k = 2~7, θ | `f = 1/(zᵏ−1)²`, `g = z^(k−1)`. k = 2 는 현수면 |
| 리치먼드 | 차수 m = 2~4, θ | `f = 1/z²`, `g = z^m`. 평면형 끝 + 에네퍼형 끝 |
| 셰르크 이중 주기 | 타일 1×1, 3×3, 5×5 | `f = 4/(1−z⁴)`, `g = z`, θ = 0. 네 끝의 주기(평행이동, 2π)로 조각을 붙임 |
| 셰르크 탑 | 층 1, 3, 5 | 같은 자료, θ = 90° (켤레). 위아래 주기 2π |
| 삼중 주기 | P · D · 자이로이드 · 네오비우스 | 삼각함수 준위면 근사를 사면체 행진법으로 |

바이어슈트라스 곡면은 모두 `X = Re( e^{iθ} ∫ (½f(1−g²), ½ i f(1+g²), f g) dz )`.
복소 적분값을 저장해 두므로 연합족 각 θ 를 바꿀 때 다시 적분하지 않습니다(현수면–나선면 변형은 매 프레임 다시 그림).

## 계산

- 적분 영역: 에네퍼는 원판 `z = r e^{iφ}`, 나머지는 로그 극좌표 `z = e^{s+iφ}`. 기준 줄에서 φ 방향, 다시 각 열을 s 방향으로 5점 가우스 적분.
- 끝(극) 근처는 선분을 잘게 나누고, 단위원 위의 극 근처는 격자를 촘촘히(s 는 sinh 눈금, φ 는 극 쪽 세제곱 눈금).
- 수치 확인: 현수면의 반지름 = cosh s, 나선면 한 바퀴의 높이 2π, k-노이드·리치먼드의 이음매 어긋남 ~1e-10, 셰르크 주기 2π.
- 주기 이음매를 건너는 긴 삼각형은 버리고, 공간에서 구·상자·원기둥으로 매끈하게 잘라 냅니다. 법선은 가우스 사상에서 바로.
- 메시 곡선: 매개변수 (φ, s) 의 눈금선. 코스타–호프만–미스는 쌍극 좌표, 평면 끝 쪽은 로그 극좌표로 바꿔 그림.

## 재질 · 배경

- 기본 **우윳빛 유리**(반투명 흰 유리 + 클리어코트 + 가장자리 광택), 무지개·맑은·푸른 유리
- 배경: 도메인 뒤틀기 fbm 성운과 세 겹의 별. 반사 환경은 어두운 스튜디오의 소프트박스가 천천히 돌며 번쩍임이 흐름.

## 조작
